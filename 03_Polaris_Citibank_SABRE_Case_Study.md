# Polaris Software Lab & Citibank — SABRE Consumer Banking & INSPIRE (1997 – 1998)

## 1. Citibank SABRE (Consumer Banking Front-End Integration)
- **Client:** Citibank Group Technology Office, Singapore
- **Role:** Consultant & L2 Technical Support
- **Environment:** Visual Basic 3.0, IBM Mainframe, CICS Transaction Server, COBOL, DB2, SNA Communication, MS SQL Server, Message-Level Interface (MLI), Graphical Desktop Manager (GDM by TTI Inc.)
- **Project Scope:**
  - SABRE was Citibank's flagship consumer banking teller and relationship management workstation across regional branches.
  - Multi-tiered architecture: Visual Basic client connected over SNA to mainframe CICS/COBOL/DB2 services via Citibank’s proprietary Message-Level Interface (MLI).
  - Maintained localized branch static data on MS SQL Server while posting financial transactions in real-time to the core mainframe ledger.
- **Key Contributions:**
  - Developed and coded new financial service transaction modules as part of regional branch gap analysis.
  - Provided Level-2 production support and emergency bug fixes for international country operations.

## 2. INSPIRE (Integrated Software Process Improvement & Regulation)
- **Role:** Project Leader & Software Architect
- **Environment:** Visual Basic 4.0/5.0, Oracle 7.1, MS SQL Server 6.5, ActiveX, ASP, HTML, VBScript
- **Project Scope:**
  - Developed an in-house enterprise Project Management & Software Engineering Process tool for Polaris's Software Engineering Process Group (SEPG).
  - Designed automated modules for CMM Level 3/4 process tracking, cumulative effort estimation, work breakdown structure (WBS) scheduling, and exception reporting.
